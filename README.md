# Deep Sky Atlas

A free-camera 3D atlas of real objects in space: exoplanet systems, black holes, pulsars, nebulae, star clusters and galaxies, each placed at its true sky position and distance.

- Drag to orbit, scroll or pinch to zoom. Scrolling over an object zooms into it.
- Click any object for its details. Close up, stars, planets, black holes, pulsars and nebulae render in real-time 3D (WebGL).
- Use the category chips to show or hide types of objects, or search by name.

The whole site is one file, `index.html`, with no build step. It works on any static host, such as GitHub Pages.
